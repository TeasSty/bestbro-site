# BEST BRO — концепт-сайт барбершопа

Демо-сайт для барбершопа **BEST BRO** (Вологда, ул. Ленинградская, 44), собранный по мотивам
их сообщества ВКонтакте — [vk.ru/bestbro35](https://vk.ru/bestbro35). Не официальный сайт.

## Что внутри

- `index.html` — вся вёрстка, стили и скрипты одним файлом (без сборки, без зависимостей).
- `assets/img/` — фото из альбомов сообщества, пережатые под веб.
- `assets/fonts/` — шрифт Oswald (700, кириллица + латиница), self-hosted `.woff2`.

Никаких внешних CDN, npm-пакетов или бэкенда — чистые HTML/CSS/JS. Можно открыть
`index.html` прямо в браузере, но часть эффектов (шрифт, изображения) корректно
подгрузится только через локальный сервер (из-за `file://`-ограничений браузера на
загрузку ресурсов), поэтому для разработки лучше поднять любой статический сервер:

```bash
# любой из вариантов
npx serve .
python -m http.server 8000
```

и открыть `http://localhost:PORT`.

## Что уже сделано

- Адаптивная вёрстка (мобильный / планшет / десктоп).
- Логотип в шапке — с ножницами по центру, как в оригинальном лого сообщества.
- Живой статус «Открыто / Закрыто» и часы по московскому времени (секция «Адрес и часы»).
- Стилизованная схема проезда (не встроенная карта — см. ниже, почему) с панелью адреса.
- Реальные цены и услуги из товаров сообщества (можно/нужно актуализировать).

## Известные ограничения и что доделать

- **Карта** — сейчас это нарисованная SVG-схема (улицы, дом, метка), а не встроенная
  интерактивная карта: реальный Яндекс/Google Maps iframe не подключали намеренно
  (в рамках прежней демо-версии на Claude Artifacts это было технически невозможно —
  строгий CSP блокирует внешние скрипты/iframe). При деплое на обычный хостинг это
  ограничение не действует — можно и нужно заменить блок `.map-visual` в `index.html`
  на настоящий Яндекс.Карты iframe или JS API.
- Цены/услуги в секции «Что под ножницами» стоит сверить с актуальным прайсом.
- Фото и адрес команды барберов — пока не добавлены (нет данных).
